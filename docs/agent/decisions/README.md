# 架构决策记录

此目录用于记录会影响未来实现或维护方式的长期决定。不要把从代码推测出的历史写成既有 ADR；只有在决策背景、选择和后果可由维护者确认时才创建记录。

## 何时新增

- 引入或替换核心框架、持久化方式、文件格式兼容策略或安全边界。
- 改变 Agent 权限、提案确认、数据迁移或发布流程的长期约束。
- 存在多个合理方案，且选定方案需要在后续任务中重复理解。

## 命名与模板

使用递增编号和简短英文主题，例如 `0001-agent-permission-boundary.md`。新记录使用：

```markdown
# 0001：决策标题

## 状态

已接受 | 已替代 | 已废弃

## 背景

说明需要解决的问题和约束。

## 决策

说明选择及其边界。

## 后果

说明收益、代价、迁移或后续维护要求。
```

创建后，在 [上级知识库索引](../README.md) 中保留本目录的路由；除非本次变更确实形成新决策，不要补造历史记录。
